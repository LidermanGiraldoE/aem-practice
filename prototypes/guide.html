01

Prepara el entorno

Clona el proyecto e inicia el servidor local.

Terminal
$ git clone https://github.com/tu-org/aem-practice.git
$ cd aem-practice && npm install
$ npx -y @adobe/aem-cli up --no-open
✓ AEM dev server up and running: http://localhost:3000/

Abre http://localhost:3000. Si ves la página de inicio, el entorno está listo.

02

Escribe el contenido

Antes del código, define cómo lo va a escribir el autor.

Crea un borrador en drafts/quote.html con el markup que entregaría AEM: un bloque con la cita y su autor.

drafts/quote.html
<div class="quote">
  <div><div>El mejor bloque es el que el autor entiende.</div></div>
  <div><div>Equipo de contenido</div></div>
</div>
03

Crea el bloque

Un archivo JS que decora y un CSS con estilos acotados al bloque.

blocks/quote/quote.js
export default function decorate(block) {
  const [quoteRow, authorRow] = [...block.children];
  const figure = document.createElement('figure');
  figure.innerHTML = `<blockquote></blockquote><figcaption></figcaption>`;
  figure.querySelector('blockquote').textContent = quoteRow?.textContent.trim() || '';
  figure.querySelector('figcaption').textContent = authorRow?.textContent.trim() || '';
  block.replaceChildren(figure);
}
✓
Campos opcionalesFíjate en el ?.: el bloque no se rompe si el autor deja el autor vacío.
04

Añade el modelo para Universal Editor

Para que el autor pueda crearlo y editarlo desde UE.

blocks/quote/_quote.json
{
  "models": [{
    "id": "quote",
    "fields": [
      { "component": "text", "name": "quote", "label": "Quote" },
      { "component": "text", "name": "author", "label": "Author" }
    ]
  }]
}

Después regenera los JSON agregados:

Terminal
$ npm run build:json
05

Valida y publica

Lint, revisión visual y pull request con enlace de preview.

Terminal
$ npm run lint
✓ 0 errors
$ git push origin quote-block

Abre https://quote-block--aem-practice--tu-org.aem.page/drafts/quote y comparte el enlace en el pull request.

✓

Solución de problemas

El puerto 3000 ya está en uso
Cierra el otro proceso o inicia el servidor en otro puerto con aem up --port 3001.
El bloque no aparece en Universal Editor
Comprueba que añadiste el id del bloque al filtro de la sección en models/_section.json y que ejecutaste npm run build:json.
Veo el contenido sin decorar
Revisa la consola: un error de sintaxis en el JS hace que el bloque se quede con el markup original. El nombre de la carpeta debe coincidir con la clase del bloque.
